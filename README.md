# ប្រព័ន្ធគ្រប់គ្រងសាលា (School Management System)

Web app ពេញលេញ៖ Node.js (ត្រូវការ ≥ 22.13) + Express + ExcelJS + SQLite (node:sqlite ដែលមានស្រាប់ មិនចាំបាច់ដំឡើងបន្ថែម) + UI ភាសាខ្មែរ។

## ដំណើរការ
```
npm install
npm start          # បើកនៅ http://localhost:3000
```
ប្តូរ Port៖ `PORT=8080 npm start` · ប្តូរ Secret៖ `JWT_SECRET=... npm start`

## គណនីសាកល្បង (សូមប្តូរមុនប្រើពិត)
- អ្នកគ្រប់គ្រង៖ `admin` / `admin123`
- គ្រូ៖ `teacher` / `teacher123`

## សិទ្ធិ
- **admin**៖ ទាំងអស់។
- **teacher**៖ មើលទាំងអស់ លើកលែងការកំណត់ប្រព័ន្ធ/អ្នកប្រើ; កែសិស្ស វត្តមាន ពិន្ទុ ដំណឹង ប័ណ្ណសរសើរ។

## ឯកសារ
`db.js` (Schema+Seed) · `server.js` (REST API+Auth) · `public/` (UI) · `school.db` (បង្កើតដោយស្វ័យប្រវត្តិ)

## Excel (នាំចូល/នាំចេញ — កែបានគ្រប់ពេល)
- **សិស្ស / គ្រូ / ប័ណ្ណសរសើរ**៖ «ទាញយក Excel» → កែក្នុង Excel → «នាំចូល Excel»។ ជួរដែលមានលេខកូដ (ឬលេខប័ណ្ណ) ដូចគ្នានឹងត្រូវ **កែ** ជួរថ្មីនឹងត្រូវ **បន្ថែម**។ «គំរូ Excel» សម្រាប់ចាប់ផ្តើមបញ្ជីថ្មី។
- **ពិន្ទុ**៖ សន្លឹកពិន្ទុតាមថ្នាក់ + ឆមាស (មានរូបមន្តសរុប/មធ្យមភាគ) នាំចូលវិញបាន។
- **ពិន្ទុប្រចាំខែ**៖ ទាញយក/គំរូ/នាំចូល Excel ១២ ខែ (ក្បាលជួរ ខែមករា … ខែធ្នូ) តាមមុខវិជ្ជា។
- **វត្តមាន**៖ ទាញយកតារាងវត្តមានប្រចាំខែ។

## ប័ណ្ណសរសើរ
- ទំព័រ «ការកំណត់សាលា» (admin)៖ ឈ្មោះសាលា នាយក ក្រសួង ទីកន្លែង និងឡូហ្គោ។
- «បង្កើតតាមចំណាត់ថ្នាក់»៖ បង្កើតប័ណ្ណសម្រាប់សិស្សពូកែ ១-N តាមមធ្យមភាគ រួចបើកបោះពុម្ពភ្លាម។
- ក្នុងទំព័របោះពុម្ព ចុចលើអក្សរណាមួយដើម្បីកែ មុនចុច «បោះពុម្ព» (Margins: None, បើក Background graphics)។
- ស៊ុមប័ណ្ណជាវល្លិ៍ក្បាច់ខ្មែរពណ៌ត្នោត គូរដោយកូដក្នុង `public/frame.js` (អាចកែទំហំ/ពណ៌បាន)។
- ពុម្ពអក្សរខ្មែរ (Moul, Battambang, Noto Sans Khmer) ដាក់ក្នុង `public/fonts` មិនត្រូវការ Internet។

## កំណត់ចំណាំ
- ពិន្ទុប្រចាំខែរក្សាទុកក្នុងតារាង `grades` ដូចគ្នា ដោយប្រើឈ្មោះខែ («ខែមករា» …) ជា `term` ដូច្នេះអាចប្រើចំណាត់ថ្នាក់ និងប័ណ្ណសរសើរតាមខែបានដែរ។
- ម៉ូឌុលហិរញ្ញវត្ថុត្រូវបានដកចេញពីកូដ។ បើ `school.db` ចាស់មានតារាង `fees`/`payments` វានៅតែមាននៅក្នុងឯកសារ ប៉ុន្តែមិនត្រូវបានប្រើទៀតទេ (ទិន្នន័យមិនត្រូវបានលុប)។
